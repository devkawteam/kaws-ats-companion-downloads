# KAW'S ATS Playground Companion

Official Windows installer downloads for KAW'S ATS Playground Companion.

## Download

Open the latest release and download `KAW-ATS-Companion-Setup-v1.0.0.exe`. The installer includes the Companion runtime and ATS telemetry plugin; convoy members do not need Node.js, Python, Visual Studio, npm, or PM2.

Install on an internal Windows drive (normally C:), start American Truck Simulator, then open KAW'S ATS Companion from the Start menu.

## Safety

This first public build is not code-signed, so Windows or a browser may show a reputation warning. Only use files from this repository and verify the published SHA-256 checksum. Do not disable antivirus protection.
